# Leap Year Finder

A simple beginner-friendly Python program that checks whether a given year is a leap year using conditional statements and the modulo operator.

## About The Project

The Leap Year Finder takes a year as input and determines whether it is a leap year.

The program follows the standard leap year rules:

- A year divisible by 4 can be a leap year.
- A year divisible by 100 is not a leap year unless it is also divisible by 400.
- A year divisible by 400 is a leap year.
